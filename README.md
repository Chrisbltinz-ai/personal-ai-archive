# Personal AI Archive

跨AI、跨设备的Markdown个人档案。此仓库计划公开：不要写入地址、电话、密码、密钥、订单、客户信息、店铺成本库存或供应商资料。

先读取 `workflow/ai-rules.md`、`workflow/preferences.md`，再按任务读取相关文件。未填写的 `{{占位符}}` 是未知事实，不得猜测。

| 目录 | 用途 |
|---|---|
| identity | 个人身份、目标；AI只读，需用户明确授权才更改 |
| workflow | 工作习惯、工具、沟通与优先级 |
| memory | 经验和决定；每条标来源、日期、确认状态 |
| skills | 能力清单、学习计划、可复用AI技能 |
| archive | 已完成项目与旧文档索引 |

接入：见 [ai-integration.md](ai-integration.md)。恢复：见 [版本恢复](workflow/version-control.md)。

本仓库是档案和规范，不是已经部署的跨平台后台同步服务。平台必须有网络/工具权限且由用户授权才能读取或写入。第三方技能原件未批量公开，避免泄露业务信息与误分发依赖。`skills/ai-skills` 为从已用流程整理的通用可移植版，不代表原件完整备份。
